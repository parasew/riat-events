# [34c3] Bitcoin / Monero / RIAT at 34c3 Chaos Communication Congress

## Event Description

In 2017 (34C3), RIAT organized assemblies for both [Monero](https://events.ccc.de/congress/2017/wiki/index.php/Assembly:Monero_Assembly) and [RIAT](https://events.ccc.de/congress/2017/wiki/index.php/Assembly:RIAT), creating a combined RIAT/Monero/Bitcoin Village at the Chaos Communication Congress.

## Historical Context

### RIAT and Monero at C3 Timeline:

**2015 (32C3):**
- RIAT participated with the [apertus AXIOM project](https://eu.axiom-camera.com)
- Talk: [apertus AXIOM at 32C3](https://media.ccc.de/v/32c3-7355-apertus_axiom)

**2016 (33C3):**
- RIAT Crypto Assembly featured crypto-based workshops with Monero
- Featured [Tomu 2FA devices](https://events.ccc.de/congress/2016/wiki/Projects:Tomu)
- Initial (mini) implementation of Monero at C3
- Bitcoin Assembly was the only other cryptocurrency assembly

**2017 (34C3):**
- Organized separate assemblies for Monero and RIAT
- Created combined RIAT/Monero/Bitcoin Village
- Monero-related talks presented at [ChaosWest self-organized stage](https://media.ccc.de/c/34C3-chaoswest)
