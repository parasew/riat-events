# 34C3: Bitcoin / Monero / RIAT Assemblies

## Summary
At 34C3, RIAT organized assemblies for **Monero** and **RIAT**, forming a combined RIAT/Monero/Bitcoin village focused on privacy tech, open hardware, and cryptocurrency research.
