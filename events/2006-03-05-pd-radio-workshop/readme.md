## Workshop Content

### Pure Data (PD) Introduction
**Pure Data (PD)** is:
- **Visual programming language**: Graphical environment for multimedia creation
- **Open source software**: Free, community-developed tool
- **Audio focus**: Particularly strong for audio processing and synthesis
- **Real-time capabilities**: Can process audio in real-time for performance or streaming

### Radio and Streaming Applications
Workshop likely covered:
- **Audio processing**: Manipulating audio with PD patches
- **Streaming setup**: Configuring PD for audio streaming
- **Radio concepts**: Basics of radio technology and internet radio
- **Live audio**: Using PD for live audio processing and broadcasting

### Technical Skills
Participants probably learned:
- **PD basics**: Creating and connecting objects in PD environment
- **Audio processing**: Filters, effects, and synthesis techniques
- **Network audio**: Streaming audio over networks
- **Project setup**: Creating complete audio streaming systems
