## Discussion Topics

### Spurious Dragon Hard Fork
**Spurious Dragon** was Ethereum's second hard fork after DAO crisis:
- **Date**: Implemented at block 2,675,000 (November 22, 2016)
- **Purpose**: State clearing and further DoS attack mitigation
- **Key changes**: 
  - State clearing: Removing empty accounts to reduce state size
  - EIP 155: Replay attack protection
  - EIP 160: EXP cost increase to prevent DoS attacks
  - EIP 161: State trie clearing
  - EIP 170: Contract code size limit

### Geth 1.5 Client Update
**Geth 1.5** (Go Ethereum client) represented major update:
- **Performance improvements**: Faster synchronization and better memory management
- **New features**: Enhanced developer tools and capabilities
- **Stability improvements**: More reliable client for network participation
- **Developer experience**: Better tools for Ethereum application development

### Ethereum Name Service (ENS)
**ENS** is decentralized naming system for Ethereum:
- **Purpose**: Human-readable names for Ethereum addresses (like `vitalik.eth`)
- **Technical basis**: Smart contract system on Ethereum
- **Use cases**: Easier address sharing, website addressing, identity management
- **Development status**: Early stages in late 2016, with growing interest
