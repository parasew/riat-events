# Miasma-Call for Reduction: Documentation as method, meta-narrations and media convergence

## Event Details

- **Date**: July 6, 2012
- **Location**: Donaufestival, Ankerbrotfabrik, Vienna
- **Organizers**: Artistic Bokeh / Miasma Cooperation
- **Type**: Performance / Prototype
- **Context**: Part of Miasma Cooperation at Donaufestival 2012 & 2013

## About the Event

**"Call for Reduction"** was an initial prototype that combined the media/formats of theatre and film. The project explored documentation as a method, meta-narrations, and media convergence.

### Project Development
Artistic Bokeh developed the technology and planned the framework for the production, representing their engagement with experimental performance formats and interdisciplinary art practices.

### Miasma Cooperation
The event was part of Miasma Cooperation's activities at Donaufestival in 2012 and 2013, representing a collaboration between Artistic Bokeh and the Miasma collective.

## Artistic Context

### Documentation as Method
The project investigated documentation not just as recording but as an artistic method and creative process in itself.

### Media Convergence
By combining theatre and film formats, "Call for Reduction" explored the convergence of different media and their potential for creating new narrative forms.

### Meta-narrations
The project engaged with self-reflexive storytelling and narratives about narrative-making processes.

## Connection to Artistic Bokeh

Artistic Bokeh's involvement included:
- **Technology development**: Creating the technical framework for the prototype
- **Production planning**: Contributing to the conceptual and logistical framework
- **Interdisciplinary practice**: Engaging with the intersection of theatre, film, and media art

## Significance
"Call for Reduction" represented Artistic Bokeh's early engagement with experimental performance formats and interdisciplinary collaboration, exploring how technology and artistic research could inform new approaches to theatre and film convergence.
