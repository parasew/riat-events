# Faceless (Mediamatic, Amsterdam)

## Summary
Faceless exhibition at Mediamatic (Amsterdam). Cooperation with Artistic Bokeh; subcuration and presentation by Matthias Tarasiewicz (Artistic Technology Research) featuring works by Addie Wagenknecht, KATSU, and other Media Arts pieces.
